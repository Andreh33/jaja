# Cuánto cuesta una página web: compara creación y mantenimiento

Para saber cuánto cuesta una web necesitas dos cifras: lo que pagas para crearla y lo que cuesta mantenerla operativa. Después debes comprobar qué trabajo cubre cada una. Dos propuestas con el mismo precio pueden incluir entregas muy distintas.

En la oferta de Latech, la creación parte de **600 € y el hosting y mantenimiento web de 60 €/mes, IVA no incluido**. Es una referencia para preparar el proyecto. El alcance se confirma antes de contratar, especialmente si necesitas más páginas, integraciones o funciones particulares.

## Un ejemplo que puedas comprobar

Para una web con la configuración base, sin extras y con doce cuotas mensuales:

| Concepto | Importe sin IVA |
| --- | ---: |
| Creación | 600 € |
| Hosting y mantenimiento: 12 × 60 € | 720 € |
| Total de creación más 12 meses | 1.320 € |
| Creación más primera mensualidad | 660 € |

El cálculo supone que empiezas desde cero y mantienes esa configuración durante los doce meses. No es un cobro anual ni aplica un descuento por pagar de otra forma. Tampoco incorpora servicios de terceros o ampliaciones que no se hayan definido en la propuesta.

Una [tienda online](/tienda/online) tiene una cuota de referencia diferente: 80 €/mes, además de la creación. No confundas la cuota de una web de presentación con la de una tienda.

## Qué hace cambiar el alcance

La cantidad de páginas importa, pero no describe todo el trabajo. Una página con un formulario sencillo puede requerir menos desarrollo que otra que deba consultar disponibilidad, registrar una reserva y avisar a varias personas.

Antes de comparar propuestas, escribe las tareas que tendrá que resolver la web. Por ejemplo: explicar tres servicios, recoger una solicitud con sus datos necesarios y permitir que el negocio actualice un horario. Después añade las dependencias: ¿hay textos preparados?, ¿se conserva un dominio?, ¿hay URLs antiguas?, ¿se conecta con una agenda?

En nuestra calculadora, marcar más de ocho páginas señala que debemos revisar el alcance. No transforma esa necesidad en un suplemento inventado ni garantiza que cualquier proyecto completo cueste la misma cantidad.

## Cinco preguntas para leer un presupuesto

1. **¿Qué entrega concreta incluye la creación?** Pide páginas, funciones, revisión de contenidos y criterios para aceptar el resultado.
2. **¿Qué cubre la cuota mensual?** Conviene distinguir soporte, mantenimiento técnico y producción de nuevos contenidos.
3. **¿Qué conceptos se pagan aparte?** Identifica herramientas externas, consumo de servicios y nuevas integraciones cuando proceda.
4. **¿Quién controla el dominio, las cuentas y los contenidos?** Deja clara también la entrega de accesos.
5. **¿Cómo se gestionan cambios y una futura salida?** Una propuesta comprensible explica ese procedimiento antes de empezar.

## El precio ayuda a decidir cuando puedes revisar las elecciones

La [calculadora de Latech](/tienda/calculadora) separa creación, extras puntuales y cuota mensual. Puedes cambiar las opciones y revisar el mensaje preparado antes de abrir WhatsApp. No necesitas registrarte para hacer esa consulta, y abrir el mensaje no significa haberlo enviado ni haber contratado.

Si todavía no sabes qué seleccionar, prepara primero un [briefing del proyecto](/briefing). Tener claras las tareas, los materiales y el responsable de mantenerlos permite comparar propuestas por su contenido. La cifra final debe acompañar a un alcance que ambas partes puedan revisar.
